# Support

GPA is currently a community-supported technical preview.

- Setup or usage question: GitHub Discussions → Q&A.
- Product idea: GitHub Discussions → Ideas.
- Reproducible defect: GitHub Issues → Bug report.
- Real task proposal: GitHub Issues → Real-world workflow.
- Security or privacy concern: private report described in `SECURITY.md`.

Please include the GPA revision, operating system, installation method and the
smallest safe reproduction. Maintainers cannot debug private account state,
accept passwords, or recover third-party data.
